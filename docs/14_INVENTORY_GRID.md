# 재고 표 입력

색상은 행, 사이즈는 열(XS부터 정렬)인 표에서 판매가능 재고를 입력한다. 변경한 칸만 강조하고 `변경사항 저장`으로 순차 저장한다. 예약·판매 수량은 각 칸 아래에 읽기 전용으로 표시한다. 미등록 조합은 빈칸이며 저장하려면 명시적으로 0 이상의 정수를 입력해야 한다.

기존 setVariantStock API의 버전 검사와 요청 ID 재시도를 유지한다. 각 칸은 입력 시작 시 버전을 보존하고, 네트워크 실패 재시도 시 같은 요청 ID를 사용한다. 성공한 칸은 편집 상태를 해제하고 실패한 칸은 값을 보존한다. 전체가 하나의 원자적 저장은 아니며 부분 성공/실패 개수를 안내한다. 저장 중에는 입력과 닫기를 비활성화한다. 조회 실패 시 저장하지 못한다. 실제 운영 재고를 테스트 값으로 변경하지 않는다.

## 현재 옵션 기준 재고 합계 — 2026-10-05

- 상품 목록의 재고, 상단 총 재고, 재고 부족·품절 필터는 현재 상품에 등록된 색상과 사이즈의 `inventory.stock`만 합산한다. 표와 목록은 `inventorySummary.js`의 옵션 선택 기준을 공유한다.
- 색상·사이즈 변경 또는 삭제 후 남아 있는 이전 재고 문서는 합계에서 제외한다. 과거 주문·판매 이력을 위한 문서는 삭제하거나 수량을 재배분하지 않으며, 판매 누계는 전체 이력을 유지한다.
- 상품 실시간 구독 갱신 시 재고 입력표도 최신 옵션을 사용한다. 예약 수량과 판매 수량을 판매가능 수량에 더하지 않는다.
- 운영 데이터에서 모션 반팔 폴로의 현재 옵션 합계는 111개이고, 이전 COFFEE BROWN 8개와 OFF WHITE&FROST BLACK 27개를 포함한 146개가 기존 잘못된 표시였다. 해당 사례와 사이즈 삭제·다른 상품·기본 옵션에 대한 회귀 검증을 추가했다.
