# 사이즈 표시 순서 — 2026-09-29

상품 상세(빠른 보기 포함)와 관리자 이미지 연결 미리보기에서 표준 의류 사이즈를 XXXS → XXS → XS → S → M → L → XL → 2XL/XXL → 3XL/XXXL 순으로 표시한다. 저장 시 sizeOptions에도 같은 순서를 적용한다. 기존 상품은 재저장 없이 화면에서 정렬된다.

sortSizeOptions는 원본 배열과 옵션 객체를 수정하지 않는다. 표준 사이즈끼리만 정렬하며 숫자·FREE·사용자 정의 옵션의 위치는 유지한다. 옵션 이름 및 해당 SKU 재고 연결은 변경하지 않는다. 입력 중 커서와 수정 대상이 바뀌지 않도록 관리자 옵션 입력 행은 입력 순서를 유지한다.

검증: XS 후행 입력 정렬, XXL/2XL 계열, 원본 배열 불변성과 옵션 객체 보존, 숫자·FREE 옵션 유지 확인.
