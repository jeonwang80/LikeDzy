# 스타일별 사이즈 가이드

상품 편집 상단 및 이미지 미리보기의 `스타일 가이드` 버튼에서 오른쪽 패널을 연다. 상품별 `measurementGuide` 필드에 cm 실측을 저장하며 색상 간 공통으로 사용한다. 기존 `sizeGuide` 문자열은 핏 설명으로 유지한다.

패널 입력은 임시 편집이다. `상품에 적용` 후 상품 편집의 `저장 및 반영`으로 저장한다. 취소·닫기·Escape·배경 클릭은 패널의 미적용 변경을 버린다. 전체 상품에 기본 수치를 자동 적용하지 않는다. `첨부 표 수치 불러오기`는 사용자가 지정한 폴로 표를 명시적으로 불러온다.

초기 표: XS/S/M/L/XL/2XL 순서. 총장 70/71/72/73/74/75, 어깨 49/50/51/52/53/54, 가슴둘레와 밑단둘레 105/110/115/120/125/130, 소매 25/25/25/25/26/26 cm. 첨부 표의 단면 표기는 사용자 확인에 따라 둘레로 정정했다.

고객 페이지는 등록된 가이드가 있을 때 버튼을 표시하고 같은 패널을 읽기 전용으로 연다. cm/in 전환은 표시만 변경한다(1in=2.54cm). 표 아래에는 수치 없는 SVG 측정 그림과 한국어/영어 설명을 제공한다. 가슴과 밑단은 타원으로 전체 둘레를 표현하고 실제 측정은 평평하게 놓은 옷의 단면을 2배 하도록 안내한다.

상품 상세는 제품 문서를 onSnapshot으로 구독하므로 관리자 저장 후 열린 고객 페이지에도 새 수치가 반영된다. 최초 등록 대상은 모션 반팔 폴로 `zBs2wWNJoONTIpTHrBNB` 한 개다. 기존 다른 필드는 변경하지 않고 updateTime 조건부 쓰기로 등록했다.

값 검증: 사이즈 이름 필수·중복 금지(XXL/2XL 동등), 모든 치수 0 초과 500 이하. 패널은 키보드 포커스를 가두고 Escape 닫기, 원래 버튼 포커스 복귀, 배경 스크롤 잠금을 지원한다. 모바일 표는 가로 스크롤 가능하다.

레이어: 상품 편집 전체 화면의 z-index는 99999다. body에 포털로 표시하는 사이즈 가이드의 z-index는 100100으로 두어 편집 화면 위에 표시한다. 독립 패널뿐 아니라 실제 ProductEditor 내부의 버튼으로 열고 입력·적용·취소를 검증한다.
