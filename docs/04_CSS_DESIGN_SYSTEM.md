# 04. 디자인 시스템

## 방향

LikeDzy는 골프 전용이 아닌 기술적 아웃도어 브랜드를 지향합니다. 큰 압축형 영문 헤드라인, 흑백 대비, 넉넉한 여백, 움직임과 날씨 대응을 설명하는 짧은 카피를 기본으로 합니다. 브랜드 스토리는 `WE LIKE / DRIVING / THE ZENITH / IN YOU`의 고정 줄바꿈과 `DRIVE THE ZENITH IN YOU.` 시그니처를 사용합니다. 헤드라인 속 `LIKE`와 `D·Z·Y`는 동일한 세이지 그린으로 강조해 브랜드명 `LIKE DZY`가 드러나도록 합니다.

## 스타일 파일

- `src/index.css`: 전역 토큰, 기본 요소, 브랜드 스토리, 상세 설명
- `Header.css`: 데스크톱 카테고리 메가메뉴와 모바일 접이식 메뉴
- `src/admin.css`: 관리자 운영 셸, 상품 목록·등록 편집기, 공용 카드·테이블·폼
- `HeroSection.css`: 히어로
- `FeaturedProducts.css`: 메인 추천 섹션
- `CollectionList.css`: 공용 상품 카드, 컬렉션, 상품 상세
- `BottomNav.css`, `IntroSplash.css`: 모바일 내비게이션과 인트로

## 반응형 원칙

- 모바일 우선이며 390px 폭에서 가로 스크롤이 없어야 합니다.
- 모바일 상품 상세는 상품명·가격, 옆으로 넘기는 큰 상품 사진, 색상·사이즈 옵션 순서로 보여줍니다. 구매 바는 스크롤 위치와 관계없이 하단 내비게이션 바로 위에 고정하고, 맨 위로 버튼은 구매 바와 겹치지 않게 표시합니다.
- 데스크톱은 상품 그리드와 상세 갤러리에 넓은 화면을 사용합니다.
- 이미지에는 비율과 fallback을 지정해 데이터가 불완전해도 레이아웃이 무너지지 않게 합니다.
- 키보드 포커스와 버튼의 접근 가능한 이름을 유지합니다.
- 데스크톱 헤더는 1차 분류를 탭으로 노출하고 메가메뉴에서 최대 5개의 2차 분류 열을 사용합니다.
- 데스크톱 헤더의 1차 분류와 브랜드 메뉴는 넓은 화면에서 기존보다 약 1.5배 큰 가변 글자 크기를 사용하고, 1100px 이하에서는 메뉴가 겹치지 않도록 축소합니다.
- 데스크톱 메가메뉴의 2차 분류 제목과 3차 카테고리 링크도 기존보다 1.5배 크게 표시해 탐색 가독성을 높입니다.
- 768px 이하에서는 데스크톱 메가메뉴를 숨기고 3레벨 접이식 메뉴로 전환합니다.

## 관리자 화면 원칙

- 고객 화면의 기술적 아웃도어 톤을 유지하되, 관리자는 정보 밀도와 반복 작업의 속도를 우선합니다.
- 좌측 내비게이션과 상단 컨텍스트 바를 고정하고 820px 이하에서는 드로어 메뉴로 전환합니다.
- 상품 등록은 `빠른 등록`을 기본 모드로 제공하고, 상품명·카테고리·가격·이미지 네 가지 필수 항목의 완료 상태를 즉시 보여줍니다.
- 상품 목록은 검색과 상태 필터를 먼저 제공하며 노출 플래그, 재고, 진열 순서를 화면 이동 없이 변경할 수 있게 합니다.
- 주문·고객 응대·통계 화면은 동일한 페이지 헤더, 버튼, 카드, 테이블 토큰을 공유합니다.
- 기준정보 화면은 좌측 등록 양식과 우측 원장 목록을 병렬 배치하고 1024px 이하에서는 세로 흐름으로 전환합니다.

기존 `DESIGN-nike.md`는 과거 레퍼런스로만 보존하며 신규 화면의 기준 문서는 이 파일입니다.

## 상품 노출 배지 색상 통일 (2026-10-05)

- `ProductBadges.jsx`와 `ProductBadges.css`를 상품 카드·상세·이미지 편집 미리보기에서 공통 사용한다. 관리자 노출 토글도 같은 색상 변수를 사용한다.
- 추천: 파란색 `#dbeafe / #1e40af`, NEW: 황금색 `#f5dfa7 / #61420c`, BEST: 녹색 `#deebc9 / #365522`, 상품 준비중: 회색 `#e5e7eb / #4b5563` (배경/글자).
- 추천·신상품·베스트 상태가 여러 개면 함께 표시한다. 기존 `badgeText`는 유지하되 중복 배지는 제거한다. 재고가 없는 상품 카드·상세는 상품 준비중 배지를 우선 표시한다.
- 미선택 관리자 토글은 흰 배경으로 구분하며 `aria-pressed`를 제공한다. 배지 목록은 좁은 화면에서 줄바꿈한다.
- 과거 테마와 관리자 미리보기의 별도 배지 색상 선언은 제거해 현재 밝은 스토어에서도 같은 색을 사용한다. 기존 상품 실시간 구독 및 저장 방식은 유지한다.

### 관리자 판매 중지·재개 구분

- 상품 관리의 판매 중지 버튼은 연한 빨강 배경/진한 빨강 글자, 판매 재개 버튼은 연한 초록 배경/진한 초록 글자로 구분한다.
- `isActive === false`인 행은 회색 배경·왼쪽 붉은 선·회색 사진과 ‘판매 중지됨’ 배지를 표시한다. 재고가 없는 상품과 수동 판매 중지는 별도로 판단한다.
- 전체 상태 필터에서 ‘판매 활성’과 ‘판매 중지됨’을 선택할 수 있다. 판매 상태 변경 시 기존 확인창과 실시간 구독을 유지한다.

### 상품 준비중 카드 음영

- 공통 `ProductCard`에서 재고 조회가 완료되고 판매 가능한 옵션이 없을 때 `is-preparing`을 적용한다. 홈 추천·컬렉션 등 이 카드를 사용하는 목록에 동일하게 표시된다.
- `ProductCard.css`: 카드 전체 회색조와 옅은 회색 바탕, 사진 대비·불투명도 감소, 색상 견본 음영을 적용한다. ‘상품 준비중 / Coming soon’ 안내는 사진 아래 기존 배지에만 표시하며 사진 중앙에는 중복 표시하지 않는다.
- 상품명·가격은 읽을 수 있는 회색으로 유지하며 상세 조회와 위시리스트 기능을 유지한다. 글자를 블러 처리하지 않는다. 재고 로딩/오류 상태는 준비중으로 오인 표시하지 않으며 재고가 생기면 실시간으로 일반 카드로 돌아온다.

## 상품 리뷰·문의 모바일 화면 (2026-10-05)

- `FeedbackDialog`와 `ProductFeedback.css`의 `pf-*` 전용 클래스를 사용한다. 지연 로딩되는 관리자 CSS에 의존하지 않는다.
- 작성창은 최대 540px, 모바일 바깥 여백 12px, 내부 여백 16px. 제목과 취소/등록 영역은 유지하고 입력 영역만 스크롤한다. `visualViewport` 높이·위치를 반영해 키보드로 화면이 좁아질 때 대응한다.
- 입력 글자는 16px, 버튼 최소 높이는 44px(등록/취소 48px). 긴 글·닉네임은 줄바꿈하고 사진 목록만 가로 스크롤한다.
- 배경 스크롤 잠금, 포커스 순환, Escape 닫기, 닫은 후 원래 버튼으로 포커스 복귀를 제공한다. 등록 중에는 중복 제출과 닫기 버튼을 막는다.
- 문의 답변은 밝은 배경 위 진한 `#202823` 글자로 표시한다. 기존 `#e2e8f0` 답변 글자는 배경과 대비가 부족해 읽히지 않았다.
- Q&A는 작성자에게 공개 글+본인 글을, 관리자에게 해당 상품의 전체 글을 실시간 구독한다. 비밀글 권한 규칙은 유지한다. 관리자 조회용 `qnaV2(productId, createdAt desc)` 색인을 배포에 포함한다.
- 모바일 상품 상세 탭의 상하 여백과 버튼 간격도 조정한다.

검증: 로컬 Firebase 에뮬레이터에서 리뷰·문의 등록, 관리자 답변 등록 후 새로고침 없는 갱신, 작성자/관리자 조회 및 다른 계정의 비밀글 비노출을 확인했다. 브라우저에서 320px/390px 레이아웃, 첨부 사진 미리보기·삭제, 취소 시 포커스 복귀를 점검했다. 실제 휴대폰 키보드는 별도 기기 검증이 필요하다. 운영 데이터는 변경하지 않았다.

## 모바일 상품 카드 이미지 (2026-10-05)

- 사용자 요청으로 모바일 정사각형/cover 변경을 철회하고 원래 표시 방식으로 복원했다.
- 홈·컬렉션 사진 영역은 기존 3 / 4.1 비율, 이미지는 contain과 0.4rem 여백을 사용한다. 원본 사진을 자르지 않고 전체 비율을 유지한다.
- 함께 변경했던 모바일 호버·빠른 보기 버튼도 기존 상태로 복원했다. 배경 처리 개선은 별도 검토하며 현재 배경은 유지한다.

## 사진별 배경색 설정

- 이미지 연결 · 미리보기에서 자동 추출/색상 선택기 직접 지정/초기화를 제공한다. 원본 사진과 비율은 유지한다.
- products.imageBackgrounds 배열에 imageUrl, mode(auto/manual), color(#RRGGBB)를 저장한다. 업로드 URL 치환 및 삭제된 사진의 설정 정리를 포함한다.
- 가장자리 8%의 불투명 픽셀을 군집화하여 최다 색상군의 평균을 사용한다. 추출 실패는 안내하며 추출 중 저장을 막는다.
- 홈·컬렉션의 현재 색상/호버 사진과 상세 사진에 적용한다. 준비중 카드의 회색 효과는 유지한다.

### 실제 사진 읽기 및 스포이트 보완

- Storage 버킷 CORS가 비어 있어 표시 가능한 이미지도 픽셀 읽기는 실패했다. 운영 도메인 4곳에 GET/HEAD 읽기 CORS를 설정했다. 기존 접근 규칙과 쓰기 권한은 유지한다.
- 자동 추출과 사진 클릭 선택이 공통 캔버스 로더를 사용한다. Firebase 이미지 URL에는 backgroundRead=v2를 붙여 기존 일반 이미지 캐시와 분리한다.
- 사진에서 색 선택: 확대 사진 클릭/터치 좌표를 원본 비율에 맞춰 환산한다. 투명 부분은 안내하며 키보드 실행은 중앙 색을 선택한다.


### 단일 색상 상품 상세 사진 복구

- 색상 하나의 사진 연결 목록이 비어 있어도 상품에 등록된 사진을 상세에서 표시한다. 기존 단일 색상 규칙을 빈 연결 검사보다 먼저 적용한다.
- 여러 색상 상품은 선택한 색상과 공통 사진만 표시해 다른 색상 사진이 섞이지 않도록 유지한다.
