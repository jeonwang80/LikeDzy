# 04. 디자인 시스템

## 방향

LikeDzy는 골프 전용이 아닌 기술적 아웃도어 브랜드를 지향합니다. 큰 압축형 영문 헤드라인, 흑백 대비, 넉넉한 여백, 움직임과 날씨 대응을 설명하는 짧은 카피를 기본으로 합니다.

## 스타일 파일

- `src/index.css`: 전역 토큰, 기본 요소, 브랜드 스토리, 상세 설명
- `src/admin.css`: 관리자 운영 셸, 상품 목록·등록 편집기, 공용 카드·테이블·폼
- `HeroSection.css`: 히어로
- `FeaturedProducts.css`: 메인 추천 섹션
- `CollectionList.css`: 공용 상품 카드, 컬렉션, 상품 상세
- `BottomNav.css`, `IntroSplash.css`: 모바일 내비게이션과 인트로

## 반응형 원칙

- 모바일 우선이며 390px 폭에서 가로 스크롤이 없어야 합니다.
- 모바일 상품 상세는 정보/옵션을 먼저 보여주고 하단에 고정 구매 바를 둡니다.
- 데스크톱은 상품 그리드와 상세 갤러리에 넓은 화면을 사용합니다.
- 이미지에는 비율과 fallback을 지정해 데이터가 불완전해도 레이아웃이 무너지지 않게 합니다.
- 키보드 포커스와 버튼의 접근 가능한 이름을 유지합니다.

## 관리자 화면 원칙

- 고객 화면의 기술적 아웃도어 톤을 유지하되, 관리자는 정보 밀도와 반복 작업의 속도를 우선합니다.
- 좌측 내비게이션과 상단 컨텍스트 바를 고정하고 820px 이하에서는 드로어 메뉴로 전환합니다.
- 상품 등록은 `빠른 등록`을 기본 모드로 제공하고, 상품명·카테고리·가격·이미지 네 가지 필수 항목의 완료 상태를 즉시 보여줍니다.
- 상품 목록은 검색과 상태 필터를 먼저 제공하며 노출 플래그, 재고, 진열 순서를 화면 이동 없이 변경할 수 있게 합니다.
- 주문·고객 응대·통계 화면은 동일한 페이지 헤더, 버튼, 카드, 테이블 토큰을 공유합니다.

기존 `DESIGN-nike.md`는 과거 레퍼런스로만 보존하며 신규 화면의 기준 문서는 이 파일입니다.
