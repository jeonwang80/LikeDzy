# 한국·베트남 스토어 통화 구성 (2026-09-28)

- 고객 언어 선택: 한국어 / KRW, English / VND. 베트남어 선택은 제거했으며 저장된 번역 데이터는 보존한다.
- 기본 언어는 한국어다. 선택은 브라우저에 저장하며 기존 vi 선택은 en으로 연결한다.
- 영어 상품·정렬·장바구니·주문은 VND 판매가를 사용한다. 원화·달러를 VND로 대신 해석하지 않는다. 가격이 없으면 구매 금액을 확정하지 않는다.
- 관리자 상품 가격은 KRW와 VND를 각각 입력한다. 고정 환율 자동 환산을 제거하여 한 통화 편집으로 다른 판매가를 덮어쓰지 않는다.
- `settings/commerce.vietnam`에 VND 배송비, 무료배송 기준, 계좌, 영어 정책, 정책 확인과 주문 활성화를 따로 관리한다. 사업자 정보는 공통이다. 기존 한국 설정은 유지한다.
- VND 배송 설정·계좌·정책이 미완성이면 주문을 개방하지 않는다. 실제 판매 개방에는 기존 App Check 및 재고 준비 조건도 필요하다.
- 주문 요청에 currency를 전달하고 서버가 해당 통화 상품 가격과 배송비로 재계산한다. 통화가 바뀐 동일 요청 키는 거부한다. KRW 요청의 기존 fingerprint와 호환된다.
- 주문 조회·관리·환불은 저장된 주문 통화를 사용한다. 통화가 없는 과거 주문은 KRW로 취급한다.
- VND 배송지 우편번호는 선택 사항이고 한국 주소 검색·현금영수증 신청은 한국어 KRW 주문에서만 표시한다.

## 검증

코드 검사와 운영 빌드 성공. 통화별 서버 계산, 재시도, 환불, 잘못된 통화·가격·설정 차단과 기존 KRW 호환 테스트를 추가했다. 운영 데이터의 가격·계좌·판매 개방 설정은 이번 코드 변경으로 수정하지 않는다.

## 배포

Functions를 먼저 반영한 뒤 프런트엔드를 배포해야 한다. 기존 KRW 요청도 지원하므로 이 순서로 호환성을 유지한다. 운영 배포 결과는 배포 기록에 기재한다.
