# 신상품 · 이벤트 팝업

## 운영 방법

- **관리자 → 운영 홈 → 신상품 · 이벤트 팝업**에서 노출 여부, 시작/종료 일시, 사진 3장, 한국어·영어 문구, 상품 보기 주소를 수정하고 저장합니다.
- 미리보기는 저장 전 내용을 보여주며, 닫기/오늘 숨김 설정에 영향을 주지 않습니다.
- 날짜 입력은 관리자 기기 시간대 기준이며 저장할 때 UTC로 변환합니다. 빈 날짜는 제한 없음입니다. 종료 시각부터 숨겨집니다.
- 기본 구성: 화이트·올리브·네이비 모션 폴로 사진 3장, 출시 안내와 30% 쿠폰 할인 안내. 첨부 원본을 웹용 JPEG로 변환했으며 총 약 940KB입니다.
- 사진은 각 슬롯에서 교체합니다. JPG/PNG/WebP 10MB 이하를 받아 웹용으로 압축 후 관리자 전용 Storage 경로에 업로드합니다. **팝업 저장 후** 고객 화면에 반영됩니다.
- 할인 문구는 광고 안내입니다. 실제 쿠폰 발급·할인율·기간은 기존 **쿠폰** 메뉴에서 별도로 관리합니다. 팝업을 눌러도 자동 할인/쿠폰 발급은 발생하지 않습니다.

## 노출과 동작

- 스토어 홈에서 인트로 종료 후 표시됩니다. 상품 상세, 컬렉션, 주문서, 관리자 화면 진입 시에는 자동 팝업이 없습니다.
- `settings/launchPopup`을 실시간 구독합니다. 문서가 없으면 기본 출시 팝업을 사용하고, 읽기에 실패하면 표시하지 않습니다.
- 닫기/ESC/상품 보기는 같은 탭의 방문 세션 동안 재노출하지 않습니다. 오늘 하루 보지 않기는 고객 기기의 다음 자정까지 숨깁니다.
- 숨김은 `campaignId`별로 저장됩니다. 문구를 수정해도 이미 닫은 고객에게 반복 노출되지 않습니다.
- 한국어/영어는 스토어 언어를 따릅니다. 버튼은 스토어 내부 주소(`/` 또는 `/?view=…`)만 지원합니다.
- 모달은 배경 스크롤·포커스를 막고, 키보드 포커스 순환, ESC 닫기, 닫은 후 포커스 복구를 제공합니다. 작은 화면에서는 모달 내부를 스크롤할 수 있습니다.

## 구현

- `src/utils/launchPromotion.js`: 기본 행사, 설정 정규화, 기간/숨김 처리
- `src/components/LaunchPromotion.jsx`: 실시간 구독과 노출 제어
- `src/components/LaunchPromotionDialog.jsx`, `LaunchPromotion.css`: 고객/관리자 공통 미리보기
- `src/components/AdminLaunchPromotion.jsx`: 운영 설정
- `public/campaigns/launch-2026/`: 기본 사진
- 기존 Firestore settings 읽기/관리자 쓰기 및 Storage settings 권한을 사용합니다. 보안 규칙·주문·쿠폰 데이터 변경은 없습니다.
