# 전체 색상 공통 이미지

사진의 적용 색상에서 `ALL · 전체 색상 공통`을 선택하면 상품의 `commonImageUrls`에 저장한다. 실제 판매 색상을 추가하지 않으며, 고객 상세에서 선택한 색상의 사진 다음에 공통 사진을 중복 없이 표시한다. 공통 사진은 색상별 대표/호버 역할에서 제외된다. 기존 사진과 신규 업로드 모두 지원하며 신규 blob 주소는 저장 시 업로드 URL로 변환한다. 사진 삭제 시 공통 참조도 함께 제거하고, 특정 색상으로 재지정하면 공통 참조를 제거한다.
